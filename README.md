# QADAM

Қазақстан тарихын жүйелі оқуға және тақырыптық тест тапсыруға арналған білім платформасы.

> Өткенді таны. Тарихты түсін. Болашаққа қадам бас.

## Не бар

- **Басты бет**: үлкен баннер, төрт тарихи кезеңнің карточкалары (компьютерде екі баған, телефонда бір баған), оқу жолы және оқушының прогресі.
- **Тарихи кезеңдер**: Ежелгі заман, Орта ғасыр, Жаңа заман, Қазіргі заман. Карточкадағы тақырып, тест және сұрақ саны дерекқордан есептеледі.
- **Тақырып беті**: атауы, қысқаша түсіндірме, толық оқу материалы, «Есте сақта» даталары мен ұғымдары, «Тестті бастау» батырмасы, алдыңғы/келесі тақырыпқа өту.
- **Тесттер**: әр тақырыптың өз тесті. Сұрақтар бір-бірден көрсетіледі, жауапты өзгертуге болады, өткен уақыт көрінеді. Жауаптар **серверде** тексеріледі, дұрыс жауаптар тест біткенше браузерге жіберілмейді. Нәтижеде пайыз, дұрыс/қате саны және әр сұраққа түсініктеме көрсетіледі.
- **Материалдар**: барлық тақырыптың қысқаша мазмұны мен негізгі даталары, кезең бойынша сүзгі.
- **Менің нәтижелерім**: тапсырылған тесттердің тарихы, орташа нәтиже, әр әрекеттің толық талдауы.
- **Профиль**: аты-жөнін, құпиясөзді өзгерту, шығу.
- **Іздеу**: жоғарғы жолақтан тақырыпты, оқиғаны немесе датаны іздеу.
- **Оқушы аккаунты**: логин мен құпиясөз (scrypt хэші), HttpOnly cookie сессиясы, кіру әрекеттерін шектеу. Тест аккаунтсыз да тапсырылады, бірақ нәтиже тек аккаунтқа кіргенде сақталады.

Дизайн: қара, қою сұр, қою қызыл/бордо, ақ және ақшыл сұр. Montserrat қаріпі жобаның ішінде (`public/assets/fonts`), сондықтан қазақ әріптері интернетсіз де дұрыс көрсетіледі. Графика (қошқар мүйіз өрнегі, Қожа Ахмет Ясауи кесенесі, Бәйтерек, қорған, қолжазба, Сыр бойы қалаларының картасы) — `public/assets/js/art.js` ішіндегі SVG.

## Іске қосу

Қажет: **Node.js 20 немесе жаңарақ**. Дерекқор — libSQL: компьютерде `data/qadam.sqlite` файлы, production ортада Turso.

```bash
npm install
npm start          # http://localhost:3000
npm test           # API тесттері
```

Бірінші іске қосқанда дерекқор кестелері құрылып, 4 кезең, 10 тақырып және 50 тест сұрағы жүктеледі (`server/seed/content.js`). Дерекқорда кезең бар болса, бастапқы мазмұн қайта жүктелмейді, сондықтан қолданыстағы деректер ешқашан қайта жазылмайды. Сақтық көшірме үшін `data/` папкасын көшіріңіз.

## Құрылым

```
server/
  app.js          API маршруттары және статикалық сайт
  index.js        жергілікті сервер (npm start)
  db.js           libSQL/Turso клиенті және кестелер
  auth.js         аккаунт, сессия, құпиясөз
  content.js      кезеңдер, тақырыптар, материалдар, статистика
  quiz.js         тест сұрақтары, тексеру, нәтижелер
  seed/content.js бастапқы оқу мазмұны мен сұрақтар
api/index.js      Vercel serverless функциясы
public/
  index.html      бір беттік қосымша
  assets/css      дизайн жүйесі
  assets/js       маршрутизатор, беттер, графика
tests/api.test.js
```
