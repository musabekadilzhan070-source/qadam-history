# QADAM

Қазақстан тарихын жүйелі оқуға және тақырыптық тест тапсыруға арналған білім платформасы.

> Өткенді таны. Тарихты түсін. Болашаққа қадам бас.

## Не бар

- **Кіру беті**: сайт ашылғанда алдымен «Кіру» және «Тіркелу» батырмалары шығады. Кіру: электрондық пошта (немесе бұрынғы логин) және құпиясөз, «Құпиясөзді ұмыттыңыз ба?». Тіркелу: аты-жөні, пошта, құпиясөз және оны қайталау. Қателер өріс жанында көрсетіледі. Мазмұн тек аккаунтқа кіргенде ашылады.
- **Басты бет**: үлкен баннер, төрт тарихи кезеңнің карточкалары (компьютерде екі баған, телефонда бір баған), жаңа жарияланған тесттер, оқу жолы және оқушының прогресі.
- **Тарихи кезеңдер**: Ежелгі заман, Орта ғасыр, Жаңа заман, Қазіргі заман. Карточкадағы тақырып, тест және сұрақ саны дерекқордан есептеледі.
- **Тек тест**: «Тақырып оқу» беті мен теориялық материалдар сайттан алынды; кезең бетінде әр тақырыптың «Тестті бастау» батырмасы бар, ескі `/topics/...` сілтемелері «Тесттер» бетіне өтеді. Тақырып мәтіндері мен тұлғалар дерекқорда өшірілмей сақталған.
- **Тесттер**: негізгі сұрақ түрлері — Викторина (біржауапты, көпжауапты), Сәйкестендіру, Хронологиялық реттілік; қосымша — суретпен берілетін сұрақ, ашық жауап, ҰБТ форматындағы контекст. Реттілік элементтері мен сәйкестендірудің оң жағы оқушыға араластырылып беріледі. Тест уақыты мен әр сұраққа уақыт серверде тексеріледі (қолтаңбалы тест сессиясы), уақыт біткенде тест өзі тексеріледі. Ұпай, жартылай ұпай, өту шегі. Дұрыс жауаптар тест біткенше браузерге жіберілмейді.
- **Тақырып эмблемалары**: 18 санаттағы 128 тарихи эмблема (`public/assets/js/emblems.js`), әр тақырыпта өз эмблемасы.
- **Менің нәтижелерім**: тапсырылған тесттердің тарихы, орташа нәтиже, әр әрекеттің толық талдауы.
- **Профиль**: аты-жөнін, поштаны, құпиясөзді өзгерту, шығу.
- **Ұсыныстар** (`/feedback`): оқушы тақырып пен мәтін жазып, организаторға ұсыныс жібереді, өз ұсыныстарын және организатордың жауабын көреді (жаңа жауап мәзірде белгіленеді). Әр оқушы тек өз ұсыныстарын көреді: бұл серверде тексеріледі.
- **Іздеу**: жоғарғы жолақтан тестті немесе тақырыпты іздеу.
- **Организатор кабинеті** (`/organizer`): PIN-кодпен кіру (код серверде, `ORGANIZER_PIN` айнымалысында). Тақырыптар, тест құрастырушы (жеті сұрақ түрі, уақыт пен ұпай баптаулары, «Оқушы ретінде қарау», жариялау алдындағы тексеру, көшірме, жасыру), сұрақтарды Excel/CSV-ге экспорттау және файлдан импорттау, «Келген ұсыныстар» (оқу, жауап беру, күйі мен күні бойынша сүзу), эмблемалар кітапханасы, оқушылар (уақытша құпиясөз беру), сурет кітапханасы, белгішелер, сайт мәтіндері мен баннер. «Сақтау» мен «Жариялау» бөлек, әр жариялау нұсқа болып сақталып, бұрынғы нұсқаға қайтаруға болады. Толығырақ: [DEPLOY.md](DEPLOY.md#организатор-кабинеті).
- **Оқушы аккаунты**: пошта (немесе бұрынғы логин) мен құпиясөз (scrypt хэші), HttpOnly cookie сессиясы, кіру әрекеттерін шектеу. Құпиясөзді поштамен қалпына келтіру Resend қызметі қосылғанда жұмыс істейді (`RESEND_API_KEY`, `MAIL_FROM`); қосылмаса, организатор кабинеттен уақытша құпиясөз береді.
- Бұрынғы «Материалдар» бөлімі сайттан толық алынды (мәзір, батырма, бет, кабинет бөлімі); ескі `/materials` сілтемелері «Тарихи кезеңдер» бетіне өтеді. Ескі деректер дерекқорда өшірілмей сақталған.

Дизайн: қара, қою сұр, қою қызыл/бордо, ақ және ақшыл сұр. Montserrat қаріпі жобаның ішінде (`public/assets/fonts`), сондықтан қазақ әріптері интернетсіз де дұрыс көрсетіледі. Графика (қошқар мүйіз өрнегі, Қожа Ахмет Ясауи кесенесі, Бәйтерек, қорған, қолжазба, Сыр бойы қалаларының картасы) — `public/assets/js/art.js` ішіндегі SVG.

## Іске қосу

Қажет: **Node.js 20 немесе жаңарақ**. Дерекқор — libSQL: компьютерде `data/qadam.sqlite` файлы, production ортада Turso.

```bash
npm install
npm start          # http://localhost:3000 (кабинет үшін .env-ке ORGANIZER_PIN=... жазыңыз)
npm test           # API тесттері
```

Бірінші іске қосқанда дерекқор кестелері құрылып, 4 кезең, 10 тақырып және 50 тест сұрағы жүктеледі (`server/seed/content.js`). Дерекқорда кезең бар болса, бастапқы мазмұн қайта жүктелмейді, сондықтан қолданыстағы деректер ешқашан қайта жазылмайды. Сақтық көшірме үшін `data/` папкасын көшіріңіз.

## Құрылым

```
server/
  app.js          API маршруттары және статикалық сайт
  index.js        жергілікті сервер (npm start)
  db.js           libSQL/Turso клиенті және кестелер
  auth.js         аккаунт, сессия, құпиясөз
  content.js      кезеңдер, тақырыптар, статистика
  quiz.js         тест сұрақтары, тексеру, нәтижелер
  org.js          организатор кабинетінің API-і (PIN, өңдеу, файлдар)
  transfer.js     сұрақтарды кестеге (xlsx/csv) жазу және кестеден оқу
  sheets.js       .xlsx және .csv файлдарын жазу/оқу
  feedback.js     оқушы ұсыныстары және организатор жауаптары
  publish.js      жариялау, нұсқалар, кері қайтару
  files.js        жүктелген файлдарды тексеру
  seed/content.js бастапқы оқу мазмұны мен сұрақтар
api/index.js      Vercel serverless функциясы
public/
  index.html      бір беттік қосымша
  organizer.html  организатор кабинеті (assets/js/org, assets/css/organizer.css)
  assets/css      дизайн жүйесі
  assets/js       маршрутизатор, беттер, графика
tests/            API және кабинет тесттері
```

## Хостинг

Негізгі жол: **Vercel + Turso** (`vercel.json` дайын). Қадамдар: [DEPLOY.md](DEPLOY.md). Балама ретінде `render.yaml` пен `Dockerfile` сақталған.
